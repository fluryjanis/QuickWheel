# QuickWheel

**QuickWheel is a lightweight browser extension that turns your middle mouse button into a radial navigation wheel.**

Hold **middle-click** or press **Alt + Q** to open the QuickWheel radial menu, then flick in a direction to perform common browser actions instantly.

## What Is QuickWheel?

QuickWheel is a **radial navigation wheel** and **mouse gesture extension** designed to make common browser actions faster.

Instead of searching through menus or moving your cursor across the browser interface, QuickWheel puts your most useful actions directly around your cursor.

**Hold → Flick → Done.**

## 8 Browser Actions

QuickWheel uses a single-ring radial menu with eight quick actions:

| Direction | Action            |
| --------- | ----------------- |
| ⬆️        | Duplicate Tab     |
| ➡️        | Focus Search      |
| ⬇️        | Copy Markdown     |
| ⬅️        | Translate Page    |
| ⬆️        | Jump to Top       |
| ➡️        | Mute / Unmute Tab |
| ⬇️        | Copy Link         |
| ⬅️        | Reopen Closed Tab |

## Why QuickWheel?

* **Radial navigation** — access browser controls directly around your cursor.
* **Mouse gestures** — use simple directional flicks instead of navigating menus.
* **Middle-click activation** — hold the middle mouse button to open the wheel.
* **Single-ring design** — keeps the interface simple and fast.
* **Native autoscroll preserved** — quick middle-clicks continue to work normally.
* **Privacy-focused** — runs entirely on your device with no analytics or external tracking.
* **Lightweight** — designed to stay out of the way until you need it.

## How It Works

1. Hold **middle-click** anywhere on a webpage, or press **Alt + Q**.
2. Move your cursor toward an action.
3. Release to perform the action.

QuickWheel automatically handles the gesture while keeping normal browser interactions available when you're not intentionally using the wheel.

## Built For Fast Browsing

QuickWheel is designed for people who want **faster browser navigation**, especially power users who frequently repeat the same actions.

It can be useful for:

* Quickly managing tabs
* Navigating long webpages
* Finding search boxes
* Copying links and Markdown
* Translating pages
* Controlling noisy media
* Restoring recently closed tabs

## Privacy

QuickWheel operates entirely on your device.

There is **no analytics, external tracking, or remote prompt processing**.
